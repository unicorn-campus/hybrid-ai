# Claude로 제안받고 H3로 생성하기

장면 설명을 그대로 영상 모델에 전달하면 음악이나 자막 요청이 대사와 섞일 수 있습니다.  
VideoKiwi는 Claude에게 입력 의도를 정리하도록 요청하고, H3에 전달할 영상과 소리 조건을 나눕니다.

## 사용하는 모델과 로그인

공식 `@anthropic-ai/claude-agent-sdk`를 사용합니다. 기본 모델은 `claude-opus-5-5`(Claude Opus 5.5)이며,  
실제 응답 모델 이름은 제안 결과에 표시합니다. `.env`의 `VIDEOKIWI_CLAUDE_MODEL`로 모델을 바꿀 수 있습니다.

서버 사용자 계정으로 Claude Code에 로그인한 세션을 사용합니다.  
앱은 API 키 인증이나 다른 클라우드 제공자로 자동 전환하지 않습니다. 구독 한도나 로그인 오류는 제안 실패로 표시합니다.  
로그인 토큰과 계정 이메일을 브라우저에 전달하지 않습니다. Mac에서 Windows 서버를 열면 Windows 서버의 로그인을 사용합니다.

제안 요청은 Claude의 서비스에서 처리합니다. 사용자가 선택한 시작과 끝 이미지, 장면 설명과 소리 설명을 전달합니다.  
영상 생성과 결과 저장은 계속 로컬 ComfyUI H3가 수행합니다.

## 제안이 적용되는 시점

제안 버튼을 누르면 원문 아래에 **제안 프롬프트 검토** 영역이 열립니다. 원래 입력 창은 원문을 보존합니다.  
검토 영역의 문장을 직접 수정한 뒤 **영상 만들기**를 누르면 수정한 제안문을 전달합니다.  
복사와 붙여넣기는 필요하지 않으며, 제안 요청 자체로 영상을 생성하지 않습니다.

제안 중에는 영상 만들기를 잠그고, 요청 중에 입력이 바뀌면 이전 입력에 대한 결과는 적용하지 않습니다.  
검토 영역을 닫거나 원문으로 되돌리면 해당 상태에 따라 원문을 사용합니다.  
자동 제안 옵션을 켰다면 영상 생성 전에 Claude에 제안을 요청합니다. 기본값은 꺼짐입니다.

## 장면과 음성을 나누는 기준

| H3 구역 | 전달하는 내용 |
|---|---|
| `integrated_multimodal_description` | 화면에 보일 피사체, 움직임, 카메라, 빛과 자막 조건을 전달합니다. |
| `overall_soundscape` | 환경음과 명시적으로 요청한 대사를 전달합니다. |
| `non_diegetic_music` | 장면 밖의 배경 음악을 전달합니다. |

장면 설명은 낭독할 대본이 아니라고 명시합니다. 대사를 요청하지 않았다면 말소리와 내레이션, 보컬을 금지합니다.  
‘하인샤 대사원’의 ‘대사원’은 발화 지시로 처리하지 않습니다. 사용자가 실제 대사를 지정했다면 해당 지시는 보존합니다.  
무음과 음악 요청도 구분합니다. 명확한 한글 자막 문구가 없으면 제안 참고 사항에 확인이 필요하다고 표시합니다.

이 처리는 모델이 조건을 따르도록 돕는 입력 개선입니다. 실제 음성이 항상 의도와 일치한다고 보장하지 않습니다.  
최종 전달 문장은 생성 기록의 **엔진에 제출한 최종 프롬프트**에서 확인할 수 있습니다.

## 실행 경계

Claude에는 입력에 대한 답변만 요청합니다. 파일 편집이나 셸 명령, MCP 도구는 사용할 수 없도록 설정합니다.  
제안에는 시간 제한과 동시 요청 제한을 두며, 실패한 요청을 자동으로 반복하지 않습니다.  
프로젝트의 개발 지침과 플러그인, 개인 메모리를 프롬프트 제안에 섞지 않도록 SDK 설정을 분리합니다.
