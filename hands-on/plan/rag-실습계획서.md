## 1. 목표

- 교육생이 RAG 세 단계(인덱싱 → 검색 → 평가)를 **파이썬 코드로 직접 만들며** 개념을 이해함
- 강사는 전체 예제 코드를 보여 주고, 교육생은 **핵심 프로그램 3개만 클론 코딩**한 뒤 본인 코드로 바꿔 끼워 실행함
- 매 실습은 "단계별 결과를 눈으로 확인"하는 출력으로 끝남. 돌아가는지 모르는 채 다음 단계로 넘어가지 않음

## 3. 예제 프로그램 구성(강사 제공)

레이어드 아키텍처 없이 **main 1개 + 핵심 모듈 1개**로 구성함. 설정값은 main 맨 위 상수에 모았고 설정 파일은 없음.

```text
hands-on/solutions/rag/
├─ README.md                  전체 흐름, 가상환경 설정(OS, 셸별), 실행 순서, 출력 형식 기호
├─ requirements.txt           인덱싱과 검색 공용 패키지
├─ .venv/                     인덱싱과 검색 공용 가상환경
├─ indexing/
│  ├─ index_docs.py           main: 로드 → 정제 → 가명처리 → 청킹 → 임베딩 → Chroma 적재(단계별 함수)
│  ├─ core_chunking.py        핵심(클론 코딩 대상): 반복 줄 찾기, 정제, 가명처리, 가명 ID, 청크 분할
│  ├─ my_chunking.py          교육생 작업 파일(함수 뼈대와 정규식 상수 제공)
│  ├─ data/                   전체 실행 결과: chroma/, chunks.json (검색기가 읽음)
│  └─ data-limit/             --limit 실행 결과(빠른 확인용, 검색기는 읽지 않음)
├─ retriever/
│  ├─ search_docs.py          main: 질문 → 벡터 + BM25 → 융합 → 리랭크 → 답변(확인 필요 분기)
│  ├─ core_hybrid.py          핵심(클론 코딩 대상): 토크나이저, BM25, 가중합 융합 / 읽고 복사: RRF, 리랭크, 가명 ID
│  ├─ my_hybrid.py            교육생 작업 파일
│  └─ run_eval.py             평가셋 22문항 실행 → logs/results.json(RAGAS 입력). 문항마다 저장, --start 재개
└─ ragas/
   ├─ requirements.txt, .venv RAGAS 전용 가상환경(ragas 0.4.3이 langchain 1.x와 같이 못 깔림)
   ├─ evaluate_ragas.py       main: results.json → 4지표 채점 → 표와 json
   ├─ core_scoring.py         핵심(클론 코딩 대상): 행 선택, 행 채점, 평균 집계
   ├─ my_scoring.py           교육생 작업 파일
   └─ eval-set.json           평가셋 22문항(답 있음 17, 답 없음 5)
```

## 4. 교육생이 클론 코딩할 핵심 프로그램(선별)

선별 기준: ① 기술 주제의 개념이 그 함수 안에 있음 ② 20 ~ 60줄로 한 교시 안에 쓸 수 있음 ③ 바꿔 끼우면 결과가 눈에 띄게 달라짐  
④ 라이브러리 호출법 암기가 아니라 처리 순서를 익히는 것. 정규식과 보조 함수는 학습 목표가 아니므로 뼈대에 완성본으로 제공함.

| 순서 | 핵심 파일 | 직접 쓰는 함수 수 | 개념 | 교시 |
|---|---|---|---|---|
| 1 | `core_chunking.py` | 5개 | 가명 ID(해시), 구분자 우선순위와 토큰 기준 크기, 머리말과 꼬리말 제거, 개인정보 치환 | W3 3-2 |
| 2 | `core_hybrid.py` | 3개 | 형태소 분석과 내용어 선택, BM25 점수, 정규화 가중합 | W4 4-2 |
| 3 | `core_scoring.py` | 3개 | 결과 정보 4칸, 4지표 `ascore`, 평균 집계 | W4 4-3 |

직접 쓰는 함수(쉬운 것부터)와 읽고 복사하는 것

- `core_chunking.py`: `member_pseudonym` → `split_into_chunks` → `clean_page_text` → `find_repeated_lines`  
  → `mask_private_info`.  
  정규식 상수(`PRIVATE_PATTERNS` 등)는 뼈대에 완성본으로 제공
- `core_hybrid.py`: `tokenize_korean` → `search_bm25` → `fuse_weighted`.  
  `build_tokenizer`, `fuse_rrf`, `rerank`, `member_pseudonym`과 가중합 보조 함수 4개는 읽고 복사
- `core_scoring.py`: `select_rows` → `score_row` → `summarize`. 평가자 생성(`build_metrics`)은 main이 제공

클론 코딩 대상에서 뺀 것(강사 제공, 읽기만): PDF 로더, Chroma 적재와 검색 호출, 답변 프롬프트와 LLM 호출, 결과 로그 저장.  
이유: 라이브러리 호출법이 대부분이라 직접 쳐도 개념 이해에 보탬이 적음. 대신 main 코드를 줄 단위 주석으로 읽게 함.

## 5. 교체 방법(클론 코딩 → 본인 코드 실행)

1. `my_chunking.py`(뼈대)에 강사 시연을 보며 같은 이름, 같은 인자의 함수를 채움. 미완성 함수는 `NotImplementedError`가 나서 어디가 비었는지 바로 보임
2. main 파일의 import 한 줄을 바꿈
   ```python
   import core_chunking as chunking   # 강사 코드로 실행
   import my_chunking as chunking     # 본인 코드로 실행 (이 줄만 바꿈)
   ```
3. 같은 명령으로 다시 실행해 단계별 출력(청크 수, 토큰 길이, 샘플)을 강사 결과와 비교함
4. 막히면 import를 되돌려 강사 코드로 뒤 단계를 계속 진행함(실습이 멈추지 않음)

같은 방식이 `my_hybrid.py`, `my_scoring.py`에도 적용됨. 수정을 반복할 때는 API를 쓰지 않는 `--mode bm25 --no-answer`로 확인함.

막혔을 때 3단계: ① 오류 메시지의 마지막 줄을 읽고 안내대로 함(키 없음, 인덱싱 미실행 등은 프로그램이 알려 줌)  
② import를 강사 코드로 되돌려 뒤 단계를 진행함 ③ 인덱싱 자체가 안 되면 강사가 배포한 `indexing/data/`를 복사함.

## 11. 위험과 대응

| 위험 | 대응 |
|---|---|
| 패키지 설치 실패(kiwipiepy 빌드 등) | 버전 고정(kiwipiepy 0.23.2 바이너리). 실패 조는 강사 `data/` 복사로 검색부터 진행 |
| Cohere 호출 제한으로 인덱싱 임베딩 실패 | 인덱싱은 호출 3회뿐. 429면 안내 후 종료하므로 1 ~ 2분 뒤 재실행. 강사 `data/` 배포본으로 대체 가능 |
| 인덱싱 중 검색 창이 색인 폴더를 잡아 삭제 실패(Windows 파일 잠금) | 코드가 단계 1 전에 폴더를 정리하고 실패 시 "검색 창을 닫고 재실행" 안내. 인덱싱 중 검색 실행 금지 |
| 같은 Chroma 폴더를 두 프로그램이 동시에 열어 결과가 흔들림 | 한 번에 한 프로그램만. 배치 실행 중에는 수동 실행 금지 |
| `--limit` 결과가 전체 색인을 덮어씀 | `--limit`는 `data-limit/`에 씀. 검색기는 Chroma 건수와 chunks.json 건수가 다르면 경고 |
| Groq 호출 제한(429)으로 run_eval, RAGAS 중단 | 조별 1대만, 조 사이 시차. run_eval은 문항마다 저장하고 `--start N` 재개. RAGAS는 `--limit` 축소 |
| Cohere 호출 제한(검색) | 체험 키는 리랭크 분당 10회. run_eval은 문항 사이 대기를 6초로 올리거나 `--mode hybrid`로. 걸리면 `--mode bm25` |
| 키 없음, 인덱싱 미실행 상태로 실행 | 프로그램이 시작 때 검사해 경로와 할 일을 안내하고 종료 |
| `rag/` 폴더만 복사해 `docs/`, `secrets/`를 못 찾음 | 저장소 통째로 clone. `secrets/.env`는 Git에 없으므로 강사가 별도 배포 |
| 교육생 코드 오류로 진도 정지 | import 한 줄 되돌려 강사 코드로 계속(5장 「막혔을 때 3단계」) |
| 같은 모델이 답하고 채점해 점수가 후할 수 있음 | README에 명시. 채점용 키 분리가 먼저이고 모델 분리는 다음 단계(12장 D5) |
