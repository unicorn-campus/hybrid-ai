## 4. C4(진행 상태)를 어떻게 볼지

### 개념 설명
C4는 「이 상담에서 일(해지, 전환, 신고 등)이 어디까지 진행되었는가」를 묻는 질문임. 라운드 2 ~ 4에서 설명을 세 번 고쳤지만  
숫자가 오르내림(뽑음 1/8 → 5/8 → 3/8, 잘못 뽑음 0/16 → 9/16 → 2/16). 틀린 예를 보면 원인은 기대 답 쪽에 있음.  

| 단위 | 기대 답(7단계 승인) | 라운드 4 추출 |
|---|---|---|
| D3-0044 | 실행 전 검토 단계로 남기겠습니다 | 아직 바꿨다고 기록하지는 마세요(바로 앞 줄, 같은 뜻) |
| D3-0029 | 주소는 공식 인증 화면에서 직접 변경해 주세요 | 없음 |
| D3-0033 | 이번 요청은 특정 카드 한 장의 정리 검토로 한정하겠습니다 | 없음 |
| D3-0023 | 전체 취소인지 일부 취소인지 확인한 뒤 결과를 안내드리겠습니다 | 없음 |

- 기대 답 8개 가운데 7개는 상담사가 다음에 할 일을 밝힌 줄임(7단계에서 지식니가 애매하다고 남긴 판단). 「일이 어디까지 진행되었나」의 답으로 보기 어려운 줄이 섞여 있어, 설명을 어느 쪽으로 고쳐도 한쪽이 틀림  
- 이 질문의 실제 사용(Q14 「가장 최근 상담에서 카드 해지를 어디까지 진행했나」)은 진행 상태 줄이 분명한 상담에서 나옴  

## 5. 판정 제안

| 문서 종류 | 추천 | 근거 |
|---|---|---|
| 카드 혜택 안내 | **통과 확정** | 라운드 3 조건(조정 3, 4와 업종 3건) 반영 뒤 X1 22/22. B5와 M2 값 같음은 라운드 3에서 사람 판정으로 통과를 승인하신 범위 안임 |
