# 역량 질문(2단계 확정본)  

> 역량 질문: 완성한 지식 그래프가 답해야 할 질문. 스키마에 넣을 범위를 정하고, 나중에 시험 기준이 됨  
> 판정: 자동 승인(사용자 지시, 2026-10-18). 기계가 읽는 판은 `competency_questions.json`  

## 1. 기본 질문 4가지(가이드 2절)  

| 질문 | 답(AI가 입력 파일에서 찾음) | 근거 |
|---|---|---|
| 도메인 | 카드사 고객 상담: 카드 약관, 카드 혜택 안내, 상담 기록 | 청크 `doc_type` 값 3종 |
| 용도 | 상담사가 고객의 보유 카드와 연결된 문서 근거와 상담 근거를 관계와 함께 찾음 | `specs/userstory.md` UFR-EVID-030 |
| 답할 질문 유형 | 아래 3절 표(사용자 질문을 빈칸 틀로 묶음) | `ragas/eval-set.json`, `group2_questions.json` |
| 쓰는 사람과 관리하는 사람 | 쓰는 사람: 상담사. 관리: 상품기획(약관), 혜택운영(혜택), 고객서비스(상담) | 청크 `owner_dept` 값 |

## 2. 사용자 질문 출처  

- `hybrid-ai-lab/ragas/eval-set.json`: Q01 ~ Q22(Q18 ~ Q22는 답이 없어야 하는 질문)  
- `hybrid-ai-lab/indexer/vector-bm25/evaluation/group2_questions.json`: E01 ~ E20  
- `hybrid-ai-lab/specs/userstory.md`: UFR-EVID-030(보유 카드 관련 문서와 상담 근거 조회)  

## 3. 역량 질문 초안 표  

| 문서 종류 | 번호 | 질문 유형(값을 빈칸으로 바꾼 틀) | 역량 질문 | 근거 사용자 질문 |
|---|---|---|---|---|
| regulation(약관) | R1 | {업무}를 정한 조항은 어디인가 | 어떤 조항이 어떤 업무를 정하고 있으며, 그 조항의 번호와 제목은 무엇인가? | UFR-EVID-030 |
| regulation(약관) | R2 | {업무}를 받으려면 어떤 조건이 필요한가 | 어떤 처리나 면제를 받으려면 충족해야 하는 조건(금액, 기간, 횟수)은 무엇인가? | Q01, E01, E11, E12 |
| regulation(약관) | R3 | {업무}는 언제까지 하고 언제 알려주나 | 회원이나 카드사가 어떤 일을 해야 하는 기한이나 미리 알려야 하는 시점은 언제인가? | Q02, Q03, Q04 |
| regulation(약관) | R4 | {상황}이면 어떻게 처리되나 | 어떤 상황(휴일, 오래 쓰지 않음, 해지 등)이 생기면 무엇이 어떻게 처리되는가? | Q05, Q06, E02, E03 |
| regulation(약관) | R5 | {이전 판}에서는 기준이 무엇이었나 | 이 약관의 판과 시행일은 무엇이며, 바뀌기 전 판은 무엇인가? | Q20, E14 |
| benefit_guide(혜택) | B1 | {카드}의 {혜택}은 얼마인가 | 어떤 카드가 어떤 혜택을 주며, 혜택의 크기(비율, 금액, 횟수)는 얼마인가? | Q07, Q09 ~ Q12 |
| benefit_guide(혜택) | B2 | {혜택}을 받으려면 무엇이 필요한가 | 혜택을 받기 위한 조건(전월 이용 실적, 신청, 대상 가맹점이나 업종)은 무엇인가? | Q08, E04, E05, E20 |
| benefit_guide(혜택) | B3 | {혜택}의 한도와 기한은 | 혜택의 한도(월, 연)와 사용 기한이나 신청 기한은 무엇인가? | Q07, Q09, Q10, E16, E19 |
| benefit_guide(혜택) | B4 | {혜택}에서 빠지는 것은 | 혜택에서 제외되는 거래나 다른 혜택과 함께 받을 수 없는 제한은 무엇인가? | E17, E18 |
| benefit_guide(혜택) | B5 | {카드}의 기본 이용 조건은 | 카드 자체의 이용 조건(결제 한도, 연회비, 발급 대상)은 무엇인가? | Q13, Q01 |
| consult_log(상담) | C1 | 고객이 {무엇}에 불만이었나 | 고객이 상담에서 불편하거나 불만이라고 말한 원인은 무엇인가? | E08, Q17 |
| consult_log(상담) | C2 | 상담사가 무엇을 안내했나 | 상담사는 고객에게 무엇을 제안하거나 안내했는가? | E07, E10, Q17 |
| consult_log(상담) | C3 | 고객이 왜 받아들였나 또는 거절했나 | 고객은 그 제안을 받아들였는가, 거절했는가, 미뤘는가, 그 이유는 무엇인가? | Q15, Q17 |
| consult_log(상담) | C4 | 어떤 조건이면 다시 생각하나 | 고객이 결정을 미루며 어떤 조건이면 다시 생각하겠다고 했는가? | Q16 |
| consult_log(상담) | C5 | {회원}의 이전 상담과 진행은 | 같은 회원의 바로 앞 상담은 어느 것이며, 주제와 진행이 어떻게 이어졌는가? | Q14, Q16, E09, UFR-EVID-030 |

- 범위 밖으로 뺀 것: 타사 카드 위약금(E15), 다른 판 약관 원문(Q20의 1.1판 본문은 청크에 없음),  
  회원 개인정보(이름, 연락처)  

## 4. 점검 체크리스트(가이드 6절)  

| 항목 | 결과 |
|---|---|
| 기본 질문 4가지에 답했는가 | 예(1절) |
| 질문이 실제 사용자 질문에서 나왔는가 | 예(질문마다 근거 번호 있음) |
| 사용자 질문 유형마다 역량 질문이 1개 이상 있는가 | 예(유형 15개, 질문 15개) |
| 답이 될 클래스나 타입 이름을 미리 쓰지 않았는가 | 예(질문 문장으로만 씀) |
| 질문에 쓰이지 않는 개념을 범위 밖으로 뺐는가 | 예(3절 끝 목록) |
| 시험용 표본의 기대 답과 답이 없어야 하는 문서를 준비했는가 | 3단계와 7단계에서 준비함 |
| 완성한 구조가 각 질문에 답하는지 확인했는가 | 8단계 채우기 시험에서 확인함 |
