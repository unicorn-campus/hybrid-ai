# 역량 질문과 답할 범위

- 상태: 확정
- 역량 질문: 지식 그래프가 답할 수 있어야 하는 질문 목록. 이 목록과 범위가 온톨로지의 「답할 범위」임
- 원본: `competency_questions.json`(이 문서는 `tools/render_step2.py`가 만듦)

## 기본 질문 4가지

| 기본 질문 | 답(초안) |
|---|---|
| 도메인 | 가상 카드사 한빛카드의 개인회원 이용약관, 카드 혜택 안내, 상담 기록. 이어지는 다른 원천은 정형 DB(회원, 카드, 상품, 가맹점, 거래) |
| 용도 | 상담을 돕는 에이전트의 그래프 검색(GraphRAG). 조항과 혜택과 상담 내용을 관계로 찾고, 여러 문서와 정형 DB를 이어 답함 |
| 답할 질문 유형 | 아래 question_types의 9가지 |
| 쓰는 사람과 관리하는 사람 | 쓰는 사람은 상담사와 감사자(회원을 지정해 조회하는 사람). 관리하는 사람은 스키마를 검토하고 승인하는 지식 담당자(이 실습에서는 강사) |

## 범위 밖으로 둔 질문

| 범위 밖으로 둔 질문 | 까닭 |
|---|---|
| 이 카드의 연회비는 브랜드별로 얼마인가? | 정형 DB의 상품연회비(ProductAnnualFee)가 이미 가진 값임. 다른 원천이 가진 데이터는 그래프에 다시 싣지 않음. 사용자 질문에도 카드별 연회비 금액을 묻는 것이 없음 |
| 이전 판 약관에서는 기준이 얼마였나?(Q20) | 문서에 현재 판(1.2)만 있어 답이 없음. 답이 없어야 하는 질문으로 시험에만 씀 |
| 회원의 월별 사용액과 거래 건수는 얼마인가? | 상담 본문에 상담사가 읽어 준 숫자가 있지만 정형 DB의 거래가 원본임. 문서 그래프에 싣지 않음 |
