# 8단계 검토 파일: 업종 맞추기 표(혜택 → 업종)

- 승인하는 것: 아래 혜택마다 이어 줄 업종 값. 후보는 LLM이 냈고, 확정은 사람이 함  
- 승인하면 일어나는 일: 확정한 행만 온톨로지 초안의 업종 맞추기 표(`maps/category.ttl`)에 적고, 기계 검사를 거쳐 승인본으로 올린 뒤 인덱싱이 그 혜택을 업종 노드에 이음(IN_CATEGORY). 확정하지 않은 행은 잇지 않음  
- 읽은 곳: `common/output/category_candidates.json`, `schema/doc-ontology/draft-ttl/maps/category.ttl`  

## 1. 한눈에 보기

업종은 가맹점을 나눈 정해진 갈래 8개임(값 목록 파일에서 읽음). 혜택의 대상 문장은 글이라서 그대로는 업종과 이어지지 않으므로, 혜택마다 업종 하나를 맞춰 주는 표가 필요함. 이 표가 있어야 「많이 쓰는 업종에 혜택을 주는 카드」 같은 질문에 답할 수 있음.

| 구분 | 건수 |
|---|---|
| 앞서 사람이 정한 혜택(이번 검토에서 뺌) | 32 |
| 이번에 검토할 혜택 | 185 |
| 그 가운데 LLM 후보가 분명한 것 | 116 |
| 그 가운데 미정(둘 이상에 걸치거나 어디에도 들지 않음) | 51 |
| 그 가운데 대상 문장이 추출되지 않아 묻지 못한 것 | 18 |

| 후보 업종 | 건수 |
|---|---|
| 식비 | 18 |
| 쇼핑 | 17 |
| 교통 | 12 |
| 주유 | 5 |
| 여행 | 5 |
| 해외 | 8 |
| 생활 | 46 |
| 교육 | 5 |

열 뜻  
- 구분: 혜택이 지금 어느 상태인지  
- 후보 업종: LLM이 고른 업종 값. 값 목록의 8개 가운데 하나  
- 건수: 그 줄에 해당하는 혜택 수
