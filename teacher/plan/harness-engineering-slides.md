## 슬라이드 2. 1-1 같은 모델, 다른 결과

- 제목: 하네스 엔지니어링: 같은 모델, 다른 결과  
- 리드문: 모델은 그대로 두고 하네스만 바꿔도 결과가 크게 달라짐  
- 시각 배치: 좌측 w 7.2″에 큰 숫자 비교 카드 2개를 위아래로(각 카드: 필 라벨 출처, 「전 → 후」 숫자 54pt, 설명 한 줄).  
  우측 w 7.4″에 「무엇이 달라졌나」 넘버 배지 리스트 3개. 하단 전폭 인용 콜아웃  
- 화면 본문 좌측 카드:  
  - 카드 1 | LangChain 코딩 에이전트 | 52.8 → 66.5 | Terminal Bench 2.0, 모델 고정(gpt-5.2-codex)

- 화면 본문 우측 「무엇이 달라졌나」:  
  1. 무엇을 보여 주나: 지침, 환경 정보, 컨텍스트

## 슬라이드 3. 1-2 Agent = Model + Harness

- 제목: 하네스 엔지니어링: Agent = Model + Harness  
- 리드문: 하네스는 에이전트에서 모델을 뺀 모든 것  
- 시각 배치: 상단 y 1.9″에 수식 한 줄(40pt, 「에이전트 = 모델 + 하네스」). 가운데 좌측에 원형 「모델(LLM)」과  
  둘레에 하네스 칩 8개. 우측에 세로 2단 카드(「잘하게 만들기」 파란 헤더 바, 「사고 안 나게 막기」 다크 헤더 바)  
- 화면 본문 칩 8개: 지침 | 도구 | 컨텍스트 | 상태 저장 | 샌드박스 | 검증 | 권한과 승인 | 트레이스와 평가  
- 화면 본문 카드:  
  - 잘하게 만들기 | 지침, 도구, 컨텍스트, 검증으로 원하는 결과를 내게 함  
  - 사고 안 나게 막기 | 종료 조건, 권한, 샌드박스, 사람 승인으로 피해를 막음  
- 출처: Böckeler, martinfowler.com(2026-04-02) / LangChain, The Anatomy of an Agent Harness(2026-03-10) / Hugging  
  Face(2026-05-25)  
- 상세 보기: `#1-2-agent--model--harness`  
- 발표자 노트:  
  - 모델은 글만 만듭니다. 도구를 실제로 실행하고, 결과를 다시 넣어 주고, 언제 멈출지 정하는 것은 모두 하네스입니다.  
  - Hugging Face 용어집은 좁은 뜻(모델을 부르고 도구를 실행하는 실행 계층)과 넓은 뜻(모델을 뺀 전부)을 나눕니다. 이 모듈은 넓은 뜻을 씁니다.  
  - 앞선 교재의 정의 "안전하고 예측 가능하게 동작하도록"은 오른쪽 아래 카드에 해당합니다. 위쪽 카드, 곧 잘하게 만드는 일도 하네스의 절반입니다.  
  - https://martinfowler.com/articles/harness-engineering.html  
  - https://blog.langchain.com/the-anatomy-of-an-agent-harness/  
  - https://huggingface.co/blog/agent-glossary

## 슬라이드 4. 1-3 프롬프트, 컨텍스트, 하네스

- 리드문: 관심이 "무엇을 말할까"에서 "어떤 환경에서 일하게 할까"로 넓어짐  
- 시각 배치: 좌측 w 5.0″에 동심 사각형 3개(안쪽 프롬프트 → 컨텍스트 → 바깥 하네스). 우측 w 9.6″에 패턴 D 표.

## 슬라이드 5. 1-4 하네스 4층 지도

- 제목: 하네스 엔지니어링: 하네스 4층 지도  
- 리드문: 미리 안내하고, 결과를 확인하고, 실행 중에 막고, 기록을 보고 고침  
- 시각 배치: 좌측 w 10.2″에 가로 띠 4개를 위에서 아래로 쌓음(층 색 약속 적용). 각 띠: 층 배지, 이름, 하는 일, 대표 장치, 장 번호 칩.  
  4층 띠에서 1 ~ 3층으로 올라가는 굽은 화살표에 「조향 루프」 라벨. 우측 w 4.4″에 인용 콜아웃 카드  
- 화면 본문 띠:  
  - 1층 미리 안내(가이드) | 시작 전에 방향을 줌 | 지침 파일, 도구 계약, 컨텍스트, 상태 저장 | 2장  
  - 2층 결과 확인(센서) | 한 일을 확인하고 되돌림 | 테스트, 스키마 검증, 평가 에이전트 | 3장  
  - 3층 실행 중 통제(가드레일) | 사고를 실행 중에 막음 | 반복 상한, 예산, 권한, 사람 승인 | 4장  
  - 4층 관측과 개선 | 기록을 보고 하네스를 고침 | 트레이스, 평가셋, 조향 루프 | 5장  
- 화면 본문 우측 카드 「통제는 코드가 집행」:  
  - 권한과 상한은 모델 바깥의 규칙이 검사함  
  - 모델이 지시를 우회하려 해도 넘을 수 없음  
  - 허용 여부를 LLM에 묻지 않음  
- 출처: Böckeler, martinfowler.com(2026-04-02) / The New Stack(2026-08-30) / KISA, 인공지능(AI) 보안 안내서 부록(2025-12)

## 슬라이드 7. 2-1 가이드: 미리 안내
