## 3. 실습 설계 초안

- 출발점: 팀 저장소의 RAG 예제(`teacher/rag`)를 감싼 LangGraph 문서 Q&A 에이전트  
- 진행: 단계마다 장치 하나를 붙이고, 같은 평가 질문 5개로 전후를 비교함

| 단계 | 붙이는 장치 | 하네스 층 | 확인 방법 |
|---|---|---|---|
| 0 | 하네스 없는 기본 에이전트 실행 | 없음 | 평가 질문 5개 점수, 토큰, 시간 기록 |
| 1 | 반복 상한과 예산 상한 | 3층 | 무한 반복을 유도하는 질문에서 정해진 횟수에 멈추고 부분 결과 반환 |
| 2 | 짧은 지침과 도구 설명 정리 | 1층 | 같은 질문에서 잘못된 도구 호출 횟수 감소 |
| 3 | 답변 스키마 검증과 근거 대조 노드 | 2층 | 근거 없는 답변이 다음 단계로 넘어가지 않음 |
| 4 | 외부 전송 도구에 사람 승인 | 3층 | 승인 전에는 실행되지 않고 대기 |
| 5 | 트레이스 기록과 평가 재실행 | 4층 | 0단계 대비 점수, 토큰, 실패 유형 비교표 |

- LangGraph의 반복 상한, 중단 후 승인 대기, 체크포인터 같은 API는 실습 코드 작성 시점에 context7로 최신 문서를 확인함.  
- 실습 코드 작성은 플로니(LangGraph), 도구 권한과 승인은 커넥니, 해설 페이지는 에듀니에게 나눠 맡기는 안을 제안함.
